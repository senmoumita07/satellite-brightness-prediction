# 🚀 Satellite Brightness Prediction using Machine Learning

## 📌 Project Overview
This project predicts satellite brightness using real-world Earth observation data.

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## 📊 Features Used
- Range to satellite
- Observer location
- Satellite position (RA, Declination)
- Range rate
- Limiting magnitude

## 🤖 Model
- Random Forest Regressor
- Achieved R² Score: 0.99

## 📈 Key Insights
- Satellite position strongly affects brightness
- Distance plays a major role in visibility

## 📌 Conclusion
The model successfully predicts satellite brightness with high accuracy using machine learning.
